## 关键路径映射

| 用途 | 路径 | 说明 |
|------|------|------|
| 基础页面类 | `bases/basePage.py` | BasePage，所有 POM 类的父类 |
| 截图工具 | `bases/captureScreen.py` | ScreenElement，图像识别核心 |
| 日志工具 | `commons/utils/myLogging.py` | `get_logger()` 统一日志 |
| 异常处理 | `commons/utils/targetNotFoundError.py` | `control_raise`, `element_raise` |
| 路径工具 | `commons/utils/getProjectRroot.py` | `GetPath().getProjectRoot()` |
| 配置读取 | `commons/utils/readconfig.py` | `INIConfigReader().getconfig()` |
| 配置管理 | `commons/utils/configmanager.py` | `ConfigManager` INI文件修改 |
| 进程管理 | `commons/utils/killProcess.py` | `kill_process_by_name()` |
| 图像模板根 | `resources/images/` | 通过 `GetPath().getImagePath()` 获取 |
| 测试数据根 | `resources/testdata/` | 通过 `GetPath().getProjectRoot()` 拼接 |
